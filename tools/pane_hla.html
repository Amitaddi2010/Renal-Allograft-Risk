Method, reference database and result ID
A donor eplet counts as mismatched when it is absent from every recipient molecule of the same class (class I: A/B/C together; class II: DRB1/3/4/5, DQB1, DPB1 β chains together and DQA1/DPA1 α chains together), which is the HLAMatchmaker intra- and interlocus comparison. Loads are counts of unique mismatched eplets. Immunogenic load counts mismatched eplets whose names appear in IE.xlsx; antibody-verified load uses the workbook's own flags. Antigen-level mismatches (first field) are the counts used in the thesis registers and the risk model.
