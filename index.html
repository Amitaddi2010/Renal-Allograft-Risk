What the study measured

Three Complementary Biological Domains

Traditional broad HLA matching provides modest risk discrimination in contemporary immunosuppression. This doctoral pipeline captures covert alloreactivity across three distinct mechanisms.

Flow Cytometric Crossmatch

Sub-CDC cellular crossmatching detects low-level donor-reactive alloantibodies binding peripheral T and B lymphocytes. Provides an essential 82.1% Specificity and 79.6% Negative Predictive Value rule-out safety gate.

B-MCS & T-MCS Channel Shifts

Non-HLA Checkpoint SNPs

Association of *PD-L1* rs4143815 with rejection (Allelic OR: 1.38, Recessive OR: 2.49, p = 0.00037). Case genotypes depart from Hardy-Weinberg equilibrium (heterozygote deficit, χ² = 68.3), the same signature as the flagged assays, so orthogonal re-genotyping is required before it can be called a risk locus.

Molecular Eplet Repertoire

Cataloged 71 Class I & 76 Class II PGIMER reference immunogenic eplets across 1,435 evaluations. Demonstrates that eplets provide qualitative antibody specificity rather than linear unweighted arithmetic burden.

Mismatched eplets by HLAMatchmaker category
Method, reference database and result ID
A donor eplet counts as mismatched when it is absent from every recipient molecule of the same class (class I: A/B/C together; class II: DRB1/3/4/5, DQB1, DPB1 β chains together and DQA1/DPA1 α chains together), which is the HLAMatchmaker intra- and interlocus comparison. Loads are counts of unique mismatched eplets. Immunogenic load counts mismatched eplets whose names appear in IE.xlsx; antibody-verified load uses the workbook's own flags. Antigen-level mismatches (first field) are the counts used in the thesis registers and the risk model.
